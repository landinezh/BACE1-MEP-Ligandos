Los scripts de este repositorio esperan encontrar aquí dos archivos (no se incluyen en el repositorio por defecto):

matriz_distancias.csv: matriz cuadrada de distancias entre todas las moléculas del estudio con las diferentes combinacines del MEP (mismo orden de moléculas en filas y columnas). Se lee con separador decimal ,; la primera columna se descarta porque corresponde a un índice/etiqueta de fila.

BACE_affinity.csv: tabla con los ID y la función de respuesta (afinidad) para el entrenamiento de los módelos.


Por temas de privacidad de los datos del grupo de investigación, los archivos originales no se publican aquí; el código se comparte para que cualquiera pueda reproducir la metodología con su propia matriz de distancias y su propio archivo de etiquetas.
